When a Bedrock agent calls a Lambda function, it relies on Action Groups which are defined using the OpenAPI Specification (OAS), currently supporting version 3.0.0. The OpenAPI schema dictates the structure of the data expected by the Lambda function and the response that the Lambda function should return to the Bedrock agent. 
In essence, the OpenAPI schema acts as a contract between the Bedrock agent and your Lambda function, specifying:
API operations: The different functions or actions the agent can perform.
Parameters: The required inputs for each API operation, including their data types (string, number, boolean, etc.).
Request body (if applicable): The structure and properties of any data passed in the request body.
Response format: The expected structure of the output returned by the Lambda function. 
Key aspects of the format
JSON-serialized string: The OpenAPI schema is provided as a JSON-serialized string.
Input and output parameters: Bedrock Agents use the OpenAPI schema to understand and route requests to the appropriate Lambda function, providing the function with structured input and processing its response.
Parameter types: The Bedrock Agent Function Resolver automatically casts parameters to the appropriate type (string, number, boolean) based on the type defined in the action group. Currently, array types are received as strings. 
Example (Conceptual)
Let's say your Lambda function performs a weather lookup. Your OpenAPI schema would define an operation like "GetWeather" with a parameter "city" of type string. The Lambda function would then expect an event with this structure and return a response, potentially with weather details, in a format also defined in the OpenAPI specification. 
In summary, the key is to ensure your Lambda function's input and output align with the OpenAPI specification defined in the Bedrock agent's action group.

            "required": true,
            "schema": {

    city = None

        if param['name'] == 'city':
            city = param['value']
        elif param['name'] == 'unit':
            unit = param['value']

    if action_group == "WeatherService" and api_path == "/getWeather" and http_method == "GET":
        if city:
